# 干瞪眼 · 好友牌馆

适配手机横屏、竖屏和桌面浏览器的网页扑克游戏。无需账号：昵称可自己输入（1–16 个字符），也可以随机生成。点自己的头像可切换不同造型。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

开发地址默认是 `http://localhost:5173`。同一 Wi-Fi 下，用手机打开 Vite 打印的 `Network` 地址。建房、复制邀请时也要从这类可访问地址进入，手机无法访问另一台设备的 `localhost`。

生产运行：

```bash
npm ci
npm run build
npm start
```

默认地址是 `http://localhost:3033`，可以用 `PORT` 修改端口。生产服务同时提供网页和 Socket.IO，部署时若接反向代理，把同一域名下的网页和 `/socket.io` 都转发给该服务，并允许 WebSocket 升级。公网好友联机需要自行部署到大家都能访问的地址。

## 游戏规则

- 好友局支持 2–6 人。人机练习可选 1–5 个机器人，机器人不查看其他人的手牌，也不读取牌堆。人机模式同样需要连到游戏服务器。
- 好友房在对局中加入只能观战。参赛座位（包括掉线保留的座位）和在线观战者共用 6 个名额，满员不能新加入。观战者看不到本局未打出的手牌，也不能操作牌局；退出或掉线立即释放名额，不会中断对局。观战者保持在线到下次开局才会入座，本局结束时可看结算与亮牌，但不参与计分。
- 好友建房可选 1、5、10、20 局，打完自动打开累计记分板。流局计入局数但不计分；玩家中途退出导致取消的局不计入。已完成的积分保留到最终记分板。人机练习不限局数。
- 2–4 人用 54 张牌，5–6 人用 108 张。每人发 5 张，领出者多发一张；首局房主领出，下一局由上局赢家领出（赢家离开或流局则由房主领出）。
- 普通牌接牌必须同牌型、同张数且刚好大一级；例外是单 `2` 压任意更小的单张，`22` 压任意更小的对子。顺子至少三张，连对至少两对，`2` 不进顺子或连对。
- 3 或 4 张同点数是炸弹，可压任何普通牌。炸弹先比张数，四张大于三张；同张数直接比点数，不需要刚好大一级（例如 `444`、`888` 都能压 `333`）。
- 王只作配牌，不能单出，也没有王炸。有多种解释的牌组，领出时先按同点数牌型，再按顺子、连对判定，同一牌型取较低点数；接牌时优先按能接上的同类牌型判定，否则再按炸弹判定。
- 其他人全都过牌时，只有最后成功出牌的人从公共牌堆摸一张，再重新领出；没底牌时直接领出。摸完仍只剩王则顺延到下一位能领出的人；若全桌只剩王，流局不计分。
- 先出完牌的人赢。牌桌实时显示全桌倍数，每局从 ×1 开始，每出一次炸弹翻倍。输家扣分 = 剩余牌数 × `2^(本局炸弹次数 + 是否留王)`，赢家拿到输家扣分之和。留一张王或多张王都只在结算时额外翻一次。例如两次炸弹且留王，剩 3 张扣 24 分。
- 每次轮到在线手动玩家都有 15 秒。超时自动出合法牌，没有合法牌就过牌。开启托管或掉线后，轮到该玩家时系统直接代打，不等满 15 秒；重连会恢复掉线前的托管设置。
- 轮到自己手动出牌时，手牌区显示「轮到你出牌」和倒计时，出牌按钮亮边，并响一声、震动一次。最后 5 秒显示即将自动出牌或过牌，每秒轻响一次。等待其他在线且未托管的玩家时可反复点「催牌」，不会重置倒计时；被催者会看到文字提示，并收到不同的音效和震动。音效和震动可以在右上角「设置」用滑动开关分别关闭，震动仅在支持的设备上生效。
- 轮到自己时，能单出或参与合法牌组的手牌会亮边，不会自动选牌。可以点选，也可以在多张手牌上横扫连续选中或取消；手牌太多时可用牌列下的箭头横向浏览。
- 每局正式结束后，所有参局玩家的剩余手牌都会在「本局结算与亮牌」里展示，包括流局。进行中的手牌仍只有自己能看到。
- 新摸的手牌会高亮并标「新」，只有摸牌者知道牌是什么。桌面牌组上方会标明出牌者。点其他玩家的头像可以丢拖鞋、玫瑰花、鸡蛋或番茄，只做互动展示，不影响对局。

## 重连与验证

- 房主可在玩家列表或头像互动菜单中移出其他玩家。被移出的座位无法重连；对局中移出玩家或主动离开会取消本局，不影响已完成的局和积分。
- 原标签页刷新可以回到原座位。掉线不会中断本局，即使全员掉线也会由系统打完当前局。非对局期间，在仍有真人在线的房间，离线超过约 5 分钟的座位会清理；没有真人在线的空闲房约 20 分钟后清理。
- 房间和积分仅保存在一个服务进程内，服务重启会清空，没有账号、持久化排行榜或跨进程同步。
- `npm test` 验证牌型、补牌、结算、机器人，以及真实 Socket.IO 联机流程。`npm run build` 检查 TypeScript 并生成生产文件。
